# Bedtime Handover

Two checkboxes, shown once a night: "The phone is in the kitchen." and "The alarm is set on the clock." Tick both and the screen goes dark with "Good night." Tap to reset.

The wording is editable and kept in `localStorage`. The ticks are never saved, so there is no history, no streak and nothing to protect. Meant for the first fortnight of a new charger station; after that the habit does the work.
