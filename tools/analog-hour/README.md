# Analog Hour

A commitment page. Pick a recurring weekly hour to be offline and get two things:

- A calendar file (`.ics`) with a weekly repeating event, in your local time zone (`TZID`), with a reminder ten minutes before.
- A square image card, “I'm offline Sundays 4 to 5pm”, drawn on a canvas on your device. Download it, or hand it to another app with the Web Share API where supported.

No community features. Nothing is stored. The sharing happens elsewhere.
