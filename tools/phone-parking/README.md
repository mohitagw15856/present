# Phone Parking Signs

A generator for printable “phones rest here” signs and folded table cards.

- Six templates: café, dinner party, meeting room, classroom, bedroom, grandparents' house.
- Edit the three lines of wording, pick one of four palette colours, choose a sign (A4 portrait) or a table card (A4 landscape, fold in half).
- The PDF is drawn on the device with jsPDF, loaded only when you press download. Nothing is uploaded.
- The preview is plain HTML and CSS; the PDF is drawn with the same geometry.
