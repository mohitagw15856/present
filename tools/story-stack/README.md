# Story Stack

One first line, told round the table. The phone shows an opening ("The last time I got properly lost was…"). Whoever holds it tells the next part for a minute or so, then passes it left. When the phone gets back to the start, the round is over.

- Forty first lines in [`data/story-lines.json`](../../data/story-lines.json). They end mid-sentence on purpose.
- No timer, no scoring, nothing stored. The phone is a baton.
