# Post It

A letter-writing prompt ("Write to the person who taught you to cook.") and a printable A4 letter page: a date line, "Dear", ruled lines at 8 mm, fold marks at thirds, and the prompt printed faintly at the top so you remember why. Address it by hand.

Thirty prompts in [`data/letter-prompts.json`](../../data/letter-prompts.json). Nothing stored.
