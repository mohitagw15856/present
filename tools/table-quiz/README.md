# Table Quiz

A pub-quiz round where every answer is a person at the table. No fact bank, nothing to look up.

1. Choose a round length (six, eight or ten questions) and press **Deal a round**.
2. The quizmaster reads each question aloud (“Who at this table has broken a bone?”). Everyone writes down a name. Phones stay down; the quizmaster's phone is the only one in use, for a few seconds a question.
3. **Reveal**: the questions come back one at a time. Whoever it is true of owns up, the table marks its sheets, and the stories follow. That is the point.

- 80 original questions in [`data/table-quiz.json`](../../data/table-quiz.json). Contributions welcome; every question must be answerable with a name at the table and safe to ask a mixed group.
- Questions do not repeat within a session until the bank is exhausted. Nothing is stored.
- **Answer sheets** prints a page of numbered lines (four sheets per A4) straight from the browser. No PDF library.
