# Conversation Roulette

For two or more people in the same room. Pick a depth (light, real, deep, or a mix), tap for a question, answer aloud, tap for the next.

- Uses the shared bank in [`data/questions.json`](../../data/questions.json).
- Questions are shuffled per session and do not repeat until the chosen depth is exhausted; then the deck is reshuffled.
- Nothing is stored. Closing the tab forgets everything.
